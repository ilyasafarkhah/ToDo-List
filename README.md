📝 Todo App

«A simple, fast, and beautiful Todo List web application built with React and CSS for managing daily tasks efficiently.»

---

📖 About

Todo App is a modern and responsive task management application designed to help users organize their daily tasks in a simple and intuitive interface.

This project is my first React project, created to practice and improve my skills in React, JavaScript, CSS, and component-based development.

The application allows users to add, complete, delete, and filter tasks. Task data is automatically stored in Local Storage, so tasks remain available even after refreshing the page.

✨ Features

- 🌙 Dark Mode / Light Mode — Switch between dark and light themes.
- ➕ Add Tasks — Quickly create new tasks.
- 🗑️ Delete Tasks — Remove unwanted tasks easily.
- ✅ Complete Tasks — Mark tasks as completed with a single click.
- 📊 Task Progress — See how many tasks are completed compared to the total.
  - Example: "3 of 7 tasks completed"
- 💾 Local Storage — Tasks are automatically saved and remain after refreshing the page.
- ⚠️ Input Validation — Prevents users from adding empty tasks.
- 🔎 Task Filtering — Filter tasks by:
  - All — Show all tasks.
  - Active — Show incomplete tasks.
  - Completed — Show completed tasks.
- 🎨 Clean UI — Simple and user-friendly interface.

🚀 Installation

1. Clone the repository

git clone https://github.com/your-username/todo-app.git

2. Navigate to the project directory

cd todo-app

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will then be available at the local development URL shown in your terminal.

💻 Usage

Using the application is simple:

1. ✏️ Enter your task in the input field.
2. ➕ Click the Add button to create the task.
3. ✅ Click on a task to mark it as completed.
4. 🗑️ Use the delete button to remove a task.
5. 🔎 Use the filters to display:
   - All — Show all tasks.
   - Active — Show incomplete tasks.
   - Completed — Show completed tasks.
6. 🌙 Toggle between Dark Mode and Light Mode.
7. 📊 Check your progress through the completed-task counter.

Your tasks are automatically saved in Local Storage, so they won't disappear when you refresh the page.
